First install

Getting past the first-run warning

Worldscape isn’t code-signed yet, so Windows and macOS may warn you the first time you open it. The steps here get past that. After the first install, the app updates itself.

Windows

Run the installer. If a blue “Windows protected your PC” window appears, choose More info, then Run anyway.

macOS
  1. Open the .dmg and drag Worldscape into Applications.
  2. Open Terminal (press Cmd+Space and type Terminal), paste this command and press Return. You only do this once. It lets macOS open an app that isn’t notarized yet.
    xattr -cr /Applications/Worldscape.app
  3. Open Worldscape from Applications as usual. If macOS still blocks it, go to System Settings → Privacy & Security and choose Open Anyway.
Linux

For the AppImage, right-click the file, open Properties and allow it to run as a program (or run chmod +x on it), then open it. The .deb and .rpm files install with your package manager.

Updates

Download once. Updates come to you.

Installed copies of Worldscape look after their own updates, and they never change anything without asking.

  1. It checks quietly

    Shortly after the app starts, and again every six hours, it looks for a newer version.

  2. It downloads in the background

    When a new version is ready, a small bar appears. Nothing installs on its own.

  3. You choose the moment

    Select Restart and update. Worldscape saves your chapters and every open pane first. If anything can’t be saved, the update is cancelled and nothing changes.

Updates are signed. The app only accepts packages signed with Worldscape’s own key.
